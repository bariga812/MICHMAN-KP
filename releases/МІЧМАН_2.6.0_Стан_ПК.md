# МІЧМАН КП 2.6.0 — стан парку керованих ПК

Версія 2.6.0 містить усі можливості 2.5.0 та додає вкладку **Стан ПК** у робочі простори IT Administration і Full Workspace.

## Нові модулі

- **Стан ПК:** оцінка 0–100, CPU по ядрах, RAM, заповнення дисків, батарея, температура за наявності датчиків і зрозумілі попередження.
- **Обладнання:** ОС, версія, архітектура, процесор, фізичні й логічні ядра, частота CPU, RAM і час запуску.
- **Мережеві адаптери:** IP/MAC кожного інтерфейсу, стан, швидкість, MTU, RX/TX, помилки та відкинуті пакети.
- **Діагностика агента:** версія, mTLS, порт, активні сеанси й передачі, розмір журналу та строк сертифіката.
- **Звіт парку:** локальний JSON зі станом усіх налаштованих агентів без паролів і приватних ключів.

Стан оновлюється автоматично раз на 60 секунд або кнопкою **Оновити стан**. Усі операції нових модулів працюють лише на читання через наявний mTLS-канал. Параметри керованих ПК не змінюються.

Встановіть `MichmanKP_Setup_2.6.0.exe` поверх попередньої версії. Дані, налаштування та чинна активація зберігаються. Для нових модулів потрібен MICHMAN Agent 2.2.0.
