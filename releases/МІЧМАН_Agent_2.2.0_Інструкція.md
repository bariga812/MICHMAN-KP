# MICHMAN Agent 2.2.0

Версія 2.2.0 містить можливості агента 2.1.0: MAC-ідентифікацію, нативну трансляцію екрана, введення з клавіатури й миші та перевірену передачу кількох файлів.

Додано read-only модулі `health`, `hardware`, `network_info` та `agent_diagnostics`. Вони збирають стан ресурсів, обладнання, адаптерів і самого агента. Дані передаються лише автентифікованому оператору через mTLS. Модулі не запускають довільні команди й не змінюють конфігурацію Windows/Linux.

Інсталятор додає агент до автозапуску поточного користувача. Постійного вікна немає; запит згоди з’являється лише перед Remote Assistance. Для встановлення запустіть `MICHMAN_Agent_Setup_2.2.0.exe` і виберіть індивідуальний пакет реєстрації, створений у консолі.
